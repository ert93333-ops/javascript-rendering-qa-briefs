# JavaScript Rendering QA Briefs

Static MVP for checking pasted initial HTML, rendered HTML, route notes, critical content notes, link snippets, lazy-loading notes, and blocked-resource notes before JavaScript-heavy SEO launches.

## Offer

Paste source/rendered samples and notes. Generate a copyable QA brief covering:

- empty app shell in initial HTML
- missing initial title and meta description
- critical content only present in rendered HTML
- JS-only or missing crawlable links
- hash-route or fragment route risk
- lazy/user-action content risk
- blocked JS/CSS/resource notes
- missing fallback or owner remediation decision

## Conversion Path

Billing is not connected. The MVP uses early-access, demo-request, and purchase-intent capture with a public-safe GitHub issue handoff.
